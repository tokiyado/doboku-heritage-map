# 土木遺産アトラス

土木学会の「選奨土木遺産」を地図から探せる、非公式のWebサイトです。
土木学会が運営・監修するものではありません。

- 2000〜2026年度の570件・674地点を収録
- 遺産名・地名での検索、地域・都道府県・選奨年度・種類での絞り込み
- 地図上の数字を押すと拡大し、ピンから各遺産の詳細を表示
- 猿島要塞・三角西港・小樽港北防波堤の3件は、周辺地形を3Dで表示

公開URL：https://tokiyado.github.io/doboku-heritage-map/

## データと写真について

- 遺産の名称・所在地・竣工年・選奨年度は、[土木学会の年度別一覧](https://www.jsce.or.jp/contents/isan/list/index.html)の表記に基づきます。旧地名も含みます。
- 座標は[土木学会の公開マップ](https://dobocolle.jsce.or.jp/digital-map/)（2026年9月27日更新）の掲載位置です。現地測量や実地確認は行っておらず、見学入口を示すものではありません。
- データの取得日は、2000〜2025年度分が2026年9月10日、2026年度分が2026年10月9日です。
- 種類（橋梁、ダム・発電など）は、このサイト独自の分類です。
- **土木学会の写真は掲載していません。** 各遺産の詳細から公式ページへリンクしています。
- 203件の遺産に、Wikimedia Commons 由来の写真を計364枚載せています（CC BY-SA・CC BY・CC0・パブリックドメイン）。写真ごとの作者・ライセンス・出典を画面と [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) に記載しています。
- 複数の施設からなる遺産では、施設ごとの写真を詳細画面で切り替えて表示します。写真の下に施設名を表示します。
- 3Dビューで選んだ自分の写真は、その画面での一時表示だけに使われ、保存も送信もされません。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体 |
| `app.js` | 検索・絞り込み・地図・詳細表示の処理 |
| `style.css` | 見た目の定義 |
| `data.json` | 遺産データ（1行に1件） |
| `coordinate-provenance.json` | 座標の出典と取得日の記録 |
| `leaflet.js` / `leaflet.css` | 地図ライブラリ Leaflet 1.9.4 |
| `photos.js` | 同梱写真の一覧（作者・ライセンス・出典・施設名） |
| `photos/` | 同梱写真（本体は長辺1280px以内・1枚300KB以下、`-thumb` は一覧用の192px正方形） |
| `sarushima*.jpg` / `misumi-quay*.jpg` | 最初に同梱した写真とその縮小版 |
| `favicon.svg` | ブラウザのタブに表示するアイコン |
| `.nojekyll` | GitHub Pages にファイルをそのまま配信させるための空ファイル |

件数・地点数・年度の表示は `data.json` から自動で算出されます。データを更新しても、`index.html` の数字を書き換える必要はありません（この README の数字は手で直します）。

背景地図、書体、3D用のライブラリと地形データは外部サービスから読み込みます。オフラインでは動作しません。

## リンクの形式

- `?q=検索語`：検索した状態で開きます（例：`?q=小樽`）。
- `?id=遺産ID`：その遺産の詳細を開いた状態で開きます（例：`?id=2000_4`）。

## 公開と更新

リポジトリ：https://github.com/tokiyado/doboku-heritage-map

このフォルダは git で管理していて、GitHub Pages（Branch：`main`、フォルダ：`/(root)`）で公開しています。写真の採否を選ぶための確認用ファイル `photo-candidates.html` は、`.gitignore` で公開対象から外しています。

更新するときは、このフォルダで次のコマンドを実行します。数分後に公開サイトへ反映されます。

```bash
git add -A
git commit -m "更新内容のメモ"
git push
```

GitHub の画面（「Upload files」）から入れる場合は、1回に100ファイルまでなので、`photos` フォルダ（724ファイル）は何回かに分けてアップロードします。

手元で確認する場合、`index.html` をダブルクリックしただけではデータを読み込めません。このフォルダで次のコマンドを実行し、`http://localhost:8000/` を開きます。

```bash
python -m http.server 8000
```

## うまく表示されないとき

- **404になる**：リポジトリの一番上に `index.html` があるか、Pages が `main` / `(root)` を指しているかを確認します。
- **一覧が出ない**：`data.json` が `index.html` と同じ階層にあるか確認します。
- **背景地図や3Dが出ない**：外部サービスとの通信状態を確認します。3Dは WebGL 対応のブラウザが必要です。
- **更新前の画面になる**：ページを再読み込みします。
